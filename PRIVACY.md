# Privacy Policy for FPV Stick Overlay

**1. Data Collection and Usage**
The "FPV Stick Overlay" Chrome Extension does not collect, store, transmit, or share any personal information, user analytics, or usage data. 

**2. Local Storage**
Any data saved by the extension, such as your visual preferences (colors, sizes) and controller calibration profiles, is stored strictly locally on your own device using Chrome's local storage mechanism. This data never leaves your browser and is not accessible to the developer or any third parties.

**3. Third-Party Services**
This extension does not use any third-party analytics, tracking, or remote code. 

**4. Changes to this Policy**
If our data practices change in the future, we will update this Privacy Policy. However, our core philosophy is to keep this tool completely local and private.

**5. Contact**
If you have any questions or concerns about this privacy policy, please reach out via the Chrome Web Store support tab or by opening an issue in this GitHub repository.
